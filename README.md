# GAS公開用 理科クイズゲーム

Google Apps Script（Webアプリ）としてそのまま公開できる、4択・全10問の理科クイズです。

## 構成

- `Code.gs`: Webアプリのエントリポイント (`doGet`)
- `index.html`: クイズUIとロジック

## コイン付与ルール

- 10問正解: 100コイン
- 8〜9問正解: 70コイン
- 6〜7問正解: 50コイン
- 4〜5問正解: 30コイン
- 0〜3問正解: 10コイン

## GASで公開する手順

1. 新規Apps Scriptプロジェクトを作成
2. `Code.gs` と `index.html` の内容を貼り付け
3. 右上の「デプロイ」→「新しいデプロイ」
4. 種類で「ウェブアプリ」を選択
5. 実行ユーザー/アクセス権を設定してデプロイ
6. 発行URLにアクセスしてゲーム開始
